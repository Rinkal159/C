* printf with data types:
* _______________________

→ in C, only label is not enough to print the values after that sentence, we must define which values will be filled in that space.
→ usually in java we write like this: 
    System.out.print("Value of a is: " + a);

→ but in c we define like this(filing entire sentence in double quotes, define data type of value in the place of value):
    printf("Value of a is: %d" , a);

* Header files
* ____________

→ Ends with .h
→ if any header file containing functions, then it only containes functional declaration, not definition.

^→ 2 types of header files:
    → "System defined" header file:
        #incluse <stdio.h>
        written inside angular brackets

    → "User defined" header files:
        #include "sum.h"
        writte inside double quotes.

^System defined header files:

stdio.h: input/output
stdlib.h: memory allocation
string.h: string functions
math.h: math functions
time.h: date and time
ctype.h: characters

stdio.h :
    printf() : prints 
    scanf() : get input
    fgets() : for string input

    ^→ scanf:

stdlib.h :
    strtol() : string to int conversion
    rand() : random number generation

    ^→ strtol:

    → it needs "3" arguments:
        1. first : the name of the string which will be converted into int.
        2. second : the address of the array of characters where the invalid part will be stored.
        3. third : base. the string will be converted into 10(decimal), 8(octal), 2(binary), 16 (hexdecimal)   or something else.

    → example:
    
        char string[] = "123abc";
        char *invalid[];

        strtol(string, &invalid, 10);

        if(invalid != "\0") {
            printf("invalid part : %s", invalid);
        } else {
            printf("valid int");
        }



string.h : 
    strlen() : length of the string (do not count '\0')
    strcmp() : compares two strings
    strcat() : concate strings
    strchr() : substring from specified character, finding starts from left.
    strstr() : substring from specified string
    strrchr() : substring from specified charcter but finding starts from right.

ctype.h :
    isalpha() : if the character is an alphabet
    isdigit() : if the character is a digit
    isalnum() : if the character is an alphabet or a digit
    islower() : if the character is in lower case
    isupper() : if the character is in upper case
    isspace() : if the character is a space

    👆🏻 if true, then returns 1, else returns 0

    toupper() : converts the character into upper case
    tolower() : converts the character into lower case

math.h :
    ceil() : rounds up
    floor() : rounds down
    round() : rounds to nearest
    trunc() : converts into int
    fabc() : gives positive value
    pow() : power 
    sqrt() : square root of given value

    → If i want only specific count of numbers after decimal point in double or float, do this 👇🏻
        in float:
            float num = 3.4567;
            printf("%.2f", num); 

        in double:
            double num = 3.4567;
            printf("%.2lf", num);
